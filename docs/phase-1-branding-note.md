# Branding Note

## Brand Identity
The application must strictly adhere to the Amman Earth Movers brand identity as established by the provided official logo. The aesthetic must feel industrial, reliable, and premium.

## Core Color Palette
Derived from the logo, the application will utilize the following scheme:
- **Orange (Accent/Primary):** To be used strategically for primary call-to-action buttons, active states, important highlights, and specific branding accents on the generated quotation document.
- **Grey (Structural/Text):** To be used for structural UI elements, typography (headers and body text), borders, and subtle backgrounds. It grounds the design and provides a professional, industrial feel.
- **White (Background):** The primary background color for the application workspace and the document canvas. Ensures a clean, spacious, and easily readable interface.

## Design Principles
- **Clean & Professional:** The User Interface (UI) should completely avoid clutter. Whitespace should be used effectively to separate form sections and quotation line items, ensuring maximum legibility.
- **Consistency:** The UI of the internal generator app and the final client-facing quotation document must feel like they belong to the exact same design system.
- **Typography:** The app should utilize a modern, strong, and highly readable sans-serif font that complements the geometric and robust nature of the logo's typography.

## Implementation Directive
The Amman Earth Movers logo must be prominently placed in the application's header/navigation, as well as at the top of the final generated quotation document. All UI components (buttons, inputs, tables) must be styled to default to the white/grey/orange color scheme before any functional logic is written.
